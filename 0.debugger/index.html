Практическое задание

Код уже готов. Необходимо исследовать его выполнение с помощью инструментов разработчика браузера.

Цель: научиться использовать Breakpoints, пошаговое выполнение, Call Stack, Scope, Watch и Console.

Пошаговая инструкция

  1. Запустите файл index.html.
  2. Найдите начало выполнения кода.
  3. Поставьте breakpoint внутри функции play.
  4. Обновите страницу, чтобы остановиться на точке останова.
  5. Переходите к следующей конструкции по шагам с помощью F10.
  6. Поставьте breakpoint внутри метода turn на 232 строке.
  7. Продолжайте выполнение до остановки в методе turn.
  8. Наведите курсор на this.playerEnemy. Если противника нет, будет undefined.
  9. Продолжайте выполнение с помощью F10 или F11. При входе внутрь функции можно увидеть работу chooseEnemy.
  10. Добавьте в Watch текущего воина: this.
  11. В Watch измените скорость воина — свойство speed.
  12. В Scope измените прочность оружия — свойство durability объекта weapon.
  13. Уменьшите здоровье выбранного противника до любого значения.
  14. В Console смените оружие противника на нож: 
    this.playerEnemy.weapon = new Knife()
  15. Продвигайтесь по коду как можно глубже, используя пошаговое выполнение, и наблюдайте за Call Stack.
  16. Поставьте breakpoint в методе isDead().
  17. Добавьте условие срабатывания breakpoint: 
    this.life == 0
  18. Продолжайте выполнение до остановки в условной точке.
  19. В Console выполните this и убедитесь, что life равно нулю.
  20. Воскресите воина, изменив значение life двойным кликом.
  21. В Breakpoints выключите все точки останова и продолжите выполнение.
  22. Из Console запустите битву с другими пользователями, вызвав функцию play с массивом персонажей.

Полезные инструменты

  • F10 — следующая строка;
  • F11 — войти внутрь функции;
  • Shift + F11 — выйти из функции;
  • F8 — продолжить выполнение;
  • Watch — отслеживание выражений;
  • Scope — текущие переменные;
  • Call Stack — цепочка вызовов;
  • Console — выполнение JavaScript-команд.
